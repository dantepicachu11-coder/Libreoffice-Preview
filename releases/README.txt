Release archives
================

LOPreview-v0.5.3.zip is the end-user release of LOPreview 0.5.3. GitHub's
release-asset upload host is unreachable from the build environment, so the
zip is stored here. It is also included in the automatically generated
"Source code" archives of the v0.5.3 tag.

Download this one file, unzip it, and follow INSTALL.md inside.
